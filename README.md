# CyberSafe

CyberSafe is a responsive static website created to promote
cybersecurity awareness and provide users with useful information
about online safety.

## Live Website

https://Ish1920-ai.github.io/CyberSafe/

## Pages

- Home
- Report a Complaint
- FAQ
- Contact

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Responsive Web Design

## Features

- Responsive design
- Semantic HTML
- Cybersecurity awareness information
- Complaint reporting form
- FAQ section
- Contact form
- Navigation between pages

## Project Structure

CyberSafe/
├── index.html
├── report.html
├── contact.html
├── README.md
└── style/

## How to Run Locally

Open `index.html` in a web browser.
